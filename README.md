# ADMA: weak-link penalisation in agri-food digital maturity assessment

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23624274.svg)](https://doi.org/10.5281/zenodo.23624274)

*Українська версія: [README_ua.md](README_ua.md)*

Replication package for the paper

> Kondratiuk, D. (forthcoming), "Benchmarking agri-food digital maturity without masking the weak link".

The repository contains every statistical input of the paper in its original form, the scripts that compute all reported numbers, and the outputs they produce.

The documentation, the workbook and the result files are available in English and Ukrainian; Ukrainian files carry the suffix `_ua` (`README_ua.md`, `excel/ADMA_workbook_ua.xlsx`, `results/*_ua.json`).

## Two ways to check the results

- **No programming:** open `excel/ADMA_workbook.xlsx`. Every calculation that can be checked by hand is written there as live Excel formulas: an ADMI calculator for the 21-statement questionnaire, the worked example, Tables 5 and 6 with all source values and links, the TOPSIS ranking, Table 4, equation (7) and the first 1 000 profiles of the experiment row by row. See its README sheet.
- **Full reproduction:** run the Python scripts below. They reproduce every number of the paper, including the full experiment on 2 x 100 000 profiles.

`scripts/verify_workbook.py` evaluates the workbook formulas with an independent engine and checks 7 533 values of each workbook (English and Ukrainian) against the Python results; they agree exactly.

## Requirements

Python 3.7 or newer and NumPy (tested with Python 3.7.9 and NumPy 1.21.5). Building and verifying the workbook additionally needs `openpyxl` and `pycel` (listed in `requirements.txt`).

```bash
python -m pip install -r requirements.txt
```

`certifi` is optional; install it if downloads fail with an SSL certificate error (common on macOS Python builds).

## Reproducing the paper

Run the scripts from the repository root. Next to every result file the scripts write a Ukrainian copy `<name>_ua.json`: the keys and codes are the same, text values (descriptions, strength of correspondence) are in Ukrainian.

**1. Computational experiment (P1–P3).** Under a minute.

```bash
python scripts/simulation_experiment.py
```

Reads the stored profiles in `data/generated/` and writes `results/simulation_experiment.json`. The profiles were generated by `scripts/generate_profiles.py` with seed 2026; each profile holds the 21 answers of the questionnaire, and regenerating them gives identical files. Mapping to the paper:

| Paper | JSON key |
|---|---|
| Worked example at the start of Section 4 | `worked_example` |
| P1, Supplementary Table S2 | `scenarios.<scenario>.P1_calibrated`, `P1_initial`, `P1_calibrated_model_adjusted_bounds`, `P1_residual_masking` |
| Equation (7), boundary band, Figure 2 | `boundary_band_calibrated` |
| Table 3, aggregation rules and asymmetry check | `scenarios.<scenario>.aggregation_rules` |
| P2, illusion of maturity | `scenarios.<scenario>.P2_integration_masking` |
| Table 4, diagnostic situations, Figure 3 | `diagnostic_situations` |
| P3, sensitivity to alpha and delta | `scenarios.<scenario>.P3_sensitivity` |

**2. Statistics mode on the stored data (P4).** Works offline.

```bash
python scripts/statistics_mode_local.py
```

Rebuilds the comparison matrix from `data/raw/eurostat/ict_c10_c12/` and `data/raw/ukrstat/ict_c10_c12/`, checks that it is identical to `data/matrix.csv`, prints Tables 5 and 6 and writes `results/statistics_mode_local.json`: indicator scores, layer scores, ADMI, levels and ranks (`countries`, `ranking`), the comparison with the unpenalised base index (`spearman_ADMI_base`), the TOPSIS comparison (`entropy_weights`, `spearman_ADMI_TOPSIS`, `pearson_ADMI_TOPSIS_values`, `spearman_TOPSIS_entropy_vs_equal`) and the proxy robustness check of Supplementary Table S3 (`proxy_robustness`). This reproduces the published values regardless of later revisions by the statistical agencies.

**3. Statistics mode on live data (optional).** Requires internet access, a few minutes.

```bash
python scripts/statistics_mode_api.py
```

Downloads the same slices from the Eurostat API and the Derzhstat data bank into `data/api_snapshot/<date>/`, rebuilds the matrix, runs the same computation and lists every value that differs from the stored data. Differences are expected over time, because both agencies revise data and add new survey years.

**4. Excel workbook (optional).**

```bash
python scripts/build_workbook.py    # rebuild excel/ADMA_workbook.xlsx and excel/ADMA_workbook_ua.xlsx
python scripts/verify_workbook.py   # compare their formulas with the Python results (about 1 min)
```

## Level classification at exact ties

Index values computed from questionnaire answers are multiples of 1/60, so a value can fall exactly on a level bound. By the rule of the paper such a value belongs to the lower level. Both implementations round the index to 12 decimals before classification so that floating-point noise cannot move a tie to the upper level.

## Data sources

- Eurostat, *ICT usage in enterprises*, thirteen datasets by NACE Rev. 2 activity (codes and DOIs in `data/README.md`), food processing C10–C12, enterprises with 10+ persons employed.
- State Statistics Service of Ukraine, *Use of information and communication technologies at enterprises*, data bank stat.gov.ua, dataflow `SSSU:DF_INFORM_COMMUN_TECH_ENTRP`, KVED 10–12.

Indicator definitions in the two surveys are harmonised (Regulation (EU) 2019/2152); the correspondence of indicators to questionnaire statements and its strength are given in Supplementary Table S1 of the paper and in `scripts/data_sources.py`. See `data/README.md` for reference years, breaks in series and coverage.

## Notes

- The simulation profiles are synthetic. They describe the behaviour of the index over the whole response space, not the state of real enterprises.
- The penalty parameters α = 0.40 and δ = 0.375 come from a separate calibration on a system dynamics model of enterprise digital transformation (Kondratiuk, 2026, doi: 10.70286/ISU-07.10.2026.013; model: doi: 10.5281/zenodo.19979159). The model works with layer scores, not with questionnaire items, so the calibration does not depend on the number of statements per block. That model is not part of this package.
- The farm-level figures for NACE section A quoted in the paper (robotics and precision farming) are taken directly from the cited sources (Eurostat `ef_mp_digi`, Derzhstat `DF_AGR_MACHINERY_AVAILABILITY`) and are not part of this package.
