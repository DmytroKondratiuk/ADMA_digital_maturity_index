# ADMA workbook: hand-checkable calculations of the paper

Every number on the calculation sheets is an Excel formula. Yellow cells are inputs you may change; blue cells are values copied from official sources (each with its link). Changing the yellow cells on Parameters recalculates every sheet.

## Sheets and the paper

- Parameters: alpha, delta and level bounds used by all formulas (Section 3.3, Table 2).
- Calculator: enter 19 questionnaire answers (1-5) and get layer scores, penalty, ADMI, level, DM_I, DM_S (equations 1-5).
- Worked_example: the profile of Section 4.1.
- Statistics_mode: Table 7 (equation 6). Uses EU_data and UA_data.
- EU_data: Eurostat values for all EU-27 countries; the leader is found with MAX/INDEX/MATCH.
- UA_data: Derzhstat values with direct download links.
- Diagnostic_situations: Table 6.
- Boundary_band: equation (7), the band of base index values in which the penalty changes the level (Section 4.2).
- Experiment_sample: the first 1 000 of the 100 000 generated profiles (uniform scenario) with all formulas row by row, and the corresponding results of the full run for comparison.
- Figure_2_band: native Excel chart of the band of equation (7) with the sample profiles whose level the penalty changed.
- Figure_3_map: native Excel chart of the diagnostic map (ADMI, DM_I) with the five situations of Table 6.

## Full experiment

- The complete experiment (2 x 100 000 profiles, 99 parameter combinations, Tables 4-5, hypotheses H1-H3) is run by scripts/simulation_experiment.py.
- The profiles are stored in data/generated/profiles_uniform.csv and data/generated/profiles_low_skewed.csv; any row can be typed into the Calculator to check it.

## Level rule

- Level = 1 + number of bounds strictly below the index value rounded to 12 decimals. A value exactly on a bound belongs to the lower level: 0.40 is level 2, 0.41 is level 3.
- Index values computed from questionnaire answers are multiples of 1/120, so exact ties occur; the rounding removes floating-point noise so that a tie is never moved to the upper level.

## Verification

- scripts/verify_workbook.py evaluates the formulas of this workbook with an independent engine (pycel) and compares 7 159 values with the Python scripts. All values agree.
- The workbook is generated by scripts/build_workbook.py from data/raw and data/generated; this README is generated together with the README sheet and has the same content.
